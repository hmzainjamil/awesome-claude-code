# Security and third-party tool review

This repository is a list of external projects. It does not audit, endorse, or control those projects. Tool behavior, permissions, dependencies, and data handling belong to each upstream maintainer and may change.

Before installing or enabling an entry:

- Inspect the original repository and current release.
- Review scripts, hooks, MCP tools, network access, filesystem access, and credentials.
- Confirm the license and provider terms.
- Test in an isolated project with synthetic data.
- Remove access and credentials if a project is unmaintained or compromised.

Do not include secrets or private exploit details in list entries or public issues. Use GitHub private vulnerability reporting when available, or contact the affected project's maintainer privately.

The CC0 license for this list does not apply to linked software. Verify each project's own terms.
