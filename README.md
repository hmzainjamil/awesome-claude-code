# Awesome Claude Code

A community resource list for discovering tools and references related to Claude Code. Entries are external projects and may change, become unavailable, or have different license, privacy, compatibility, and maintenance terms.

## How to use this list

Treat each link as a starting point for your own review. Before installing or enabling a tool:

- Check the original project, maintainer, latest release, and supported Claude Code version.
- Read install scripts, plugin permissions, MCP tool access, and data handling.
- Confirm license and provider terms.
- Test in a separate project with non-sensitive data.
- Recheck links and status because this list does not guarantee current operation.

There is no executable product, root package, shared configuration, runtime, or test suite in this repository. Clone or browse the list and follow the original source for each project.

## Curation standard

An entry should include its name, category, direct source link, short factual description, license when known, and date checked. Mark unverified or experimental entries clearly. Do not claim production readiness, safety, popularity, maintenance, or compatibility without current evidence.

The previous README included unsupported adoption, update-frequency, dead-link, benchmark, test-coverage, case-study, integration, and performance claims. Those claims are removed until independently documented.

## Contribute

Use GitHub pull requests to propose additions or corrections. Include the source link and evidence for claims. Do not submit secrets or private project data.
